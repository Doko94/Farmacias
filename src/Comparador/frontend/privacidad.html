Privacidad y recetas

Información clara sobre el tratamiento de archivos y datos personales.

Procesamiento en la página pública

Las fotografías se procesan localmente en tu navegador mediante OCR. El archivo y el texto detectado no se envían al servidor de AhorraMed ni se guardan en una base de datos. Al cerrar o recargar la página se eliminan de la memoria del navegador. La biblioteca de OCR se descarga desde jsDelivr, pero la receta no se entrega a ese proveedor.

Endpoint backend opcional

Si una instalación conecta expresamente el backend Python, el archivo se procesa temporalmente en memoria para extraer texto y no se conserva después de responder. No se utiliza con fines comerciales. Se rechazan archivos inválidos, protegidos, excesivamente grandes o con firmas que no coincidan con su formato.

Datos sensibles

Una receta puede contener nombre, RUT, dirección, diagnóstico y datos del profesional. Recomendamos ocultar esos campos antes de subirla cuando no sean necesarios. AhorraMed intenta excluirlos del listado de medicamentos, pero el texto OCR puede contener errores.

Contacto

Para consultas de privacidad o una instalación administrada, utiliza el canal de contacto informado por el responsable de la plataforma.
